## 🗃️ مخطط قاعدة البيانات المقترح

كل خدمة من الخدمات السابقة تكون Record مستقل في قاعدة البيانات بالشكل التالي:

### جدول: `services`

| الحقل | النوع | الوصف |
|-------|-------|-------|
| `id` | INT (PK) | المعرف الفريد |
| `name` | VARCHAR | اسم الخدمة (عربي / إنجليزي) |
| `slug` | VARCHAR (Unique) | المعرف النصي للـ URL |
| `description` | TEXT | وصف تفصيلي للخدمة |
| `short_description` | VARCHAR | وصف مختصر للعرض في القوائم |
| `category_id` | INT (FK) | معرف القسم الرئيسي |
| `subcategory_id` | INT (FK, Nullable) | معرف القسم الفرعي |
| `price` | DECIMAL | السعر الأساسي |
| `price_type` | ENUM | نوع التسعير (fixed / hourly / per_page / per_word) |
| `image` | VARCHAR | مسار صورة الخدمة |
| `icon` | VARCHAR | أيقونة الخدمة (emoji أو class) |
| `is_active` | BOOLEAN | حالة الظهور (true / false) |
| `is_featured` | BOOLEAN | خدمة مميزة في الصفحة الرئيسية |
| `sort_order` | INT | ترتيب العرض |
| `meta_title` | VARCHAR | عنوان SEO |
| `meta_description` | TEXT | وصف SEO |
| `created_at` | TIMESTAMP | تاريخ الإنشاء |
| `updated_at` | TIMESTAMP | تاريخ آخر تعديل |

### جدول: `categories`

| الحقل | النوع | الوصف |
|-------|-------|-------|
| `id` | INT (PK) | المعرف الفريد |
| `name` | VARCHAR | اسم القسم |
| `slug` | VARCHAR (Unique) | المعرف النصي |
| `icon` | VARCHAR | الأيقونة |
| `description` | TEXT | وصف القسم |
| `parent_id` | INT (FK, Nullable) | المعرف الأب (لدعم الأقسام الفرعية) |
| `sort_order` | INT | ترتيب العرض |
| `is_active` | BOOLEAN | حالة الظهور |

### جدول: `subcategories`

| الحقل | النوع | الوصف |
|-------|-------|-------|
| `id` | INT (PK) | المعرف الفريد |
| `name` | VARCHAR | اسم القسم الفرعي |
| `slug` | VARCHAR (Unique) | المعرف النصي |
| `category_id` | INT (FK) | معرف القسم الرئيسي |
| `sort_order` | INT | ترتيب العرض |
| `is_active` | BOOLEAN | حالة الظهور |

## ✅ ملاحظات تنفيذية

1. **كل خدمة Record مستقل**: تقدر من لوحة التحكم تضيف خدمة جديدة أو تعدل الاسم والوصف والسعر والصورة والقسم وحالة الظهور بدون لمس الكود.
2. **الـ CV Builder** يبقى منتج/صفحة مستقلة داخل الموقع.
3. **الـ 6 أقسام الرئيسية** في الـ Navbar، والخدمات الفرعية تظهر كصفحات داخلية أو mega menu.
4. **التسويق لخدمات الأصالة** يكون بصيغة فحص ومراجعة وتحسين، بدون وعود بنسب محددة.
5. **لغة الواجهة**: عربية أساسية مع دعم RTL، مع مصطلحات إنجليزية (SPSS, R, ATS, IoT) كما هي.
