## ثانياً: المستحقات الخارجية (الدليل التشغيلي للنشر الحقيقي)

1. **GitHub:** إنشاء مستودع → `git remote add origin <url>` → `git push -u origin v10 && git push -u origin main`
2. **Render:** New → Blueprint → ربط المستودع → تُقرأ `render.yaml` تلقائياً (خدمتان: web + api، فرانكفورت، Node 20.19.0)
3. **Supabase:** إنشاء مشروع → SQL Editor → تشغيل `supabase/schema.sql` → نسخ URL + service_role key إلى لوحة Render
4. **واتساب:** الرقم الحقيقي في `NEXT_PUBLIC_WHATSAPP_NUMBER` (مثال: `966501234567`)
5. **قرار zip:** حذف `public/v5-screenshots.zip` قبل أول نشر (النسخة الأصلية محفوظة في `download/baseline-v5/` بصماتها)

## رابعاً: قواعد الحوكمة المكتسبة (دروس موثقة)

1. **القاعدة الأم:** Chat history describes intent. Git, runtime, deployment, and artifacts prove state.
2. **قاعدة الزومبي:** خوادم standalone تنجو من قاتل العمليات — القتل بـ `kill -9 <PID>` من `ss` حصراً (لا `fuser -k`)، والتحقق أن HTML المُخدَّم يحمل بصمة البناء الحالي.
3. **قاعدة القياس الواحد:** الخادم + القياسات في استدعاء bash واحد.
4. **قاعدة العربية:** سكربت متصل = صفر تباعد حروف (الإقران اللاتيني وحده يستخدم التباعد).
5. **قاعدة إعادة التدوير:** البيئة تُعاد من آخر حالة git — الأدلة مكانها داخل git لا خارجه (خسارة research/ درس 2026-09-20).
