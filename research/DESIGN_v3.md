# DESIGN v3 — «التحسين الذكي» (Refinement Pass)

> المبدأ الحاكم من تعليمات المستخدم: **تحسين موجّه عالي القيمة لا إعادة بناء**.
> الهوية تُصان (أم سارة، داكن غابي دافئ + ذهبي + زمردي)، الوظائف لا تُمس.

## 1) مدخلات القرار (الأدلة)

**فيديوهات Pinterest الثلاثة** (تحليل VLM كامل في `research/pinterest-videos/`):
- AICM (فيديو1): عمق طبقي — حبيبات 2–5% + عتبات ضوئية ضبابية؛ تجنّب «الفراغ المسطح»
- Portals (فيديو2): مجاز بصري تجريدي «مسار معالجة» بدل الصور الجاهزة؛ هيرو غير متماثل
- UNBOT (فيديو3): `cubic-bezier(0.16,1,0.3,1)` لكل الحركات؛ stagger متدرج؛ مؤشر مخصص

**مراجع GitHub** (`research/github-refs/`):
- motion-primitives: `Magnetic` (نابض stiffness 26.7/damping 4.1)، `ScrollProgress` (useScroll+useSpring)، `TextEffect` (كشف كلمة-بكلمة مع blur)، `AnimatedNumber`
- space-portfolio: هيرو غير متماثل (نص + عنصر بصري)
- play-nextjs: انضباط الحاوية والـ CTA
- react-bits/magicui: جودة مكونات، لكن معظمها ثقيل — نأخذ الأنماط لا المكتبات

**المكدس الحالي**: framer-motion@12 موجود ← يُستخدم (لا مكتبة جديدة). Lenis موجود. Tailwind 4.

## 3) نظام التحسين v3 — عنصر واحد متماسك

### أ. هيرو غير متماثل (RTL)
- عمود نصي يمين (بداية القراءة): شارة → عنوان عملاق بكشف كلمة-بكلمة → وصف → CTA مغناطيسي → صف ثقة
- مرساة بصرية يسار: **مدار المعرفة (Knowledge Orbit)** — SVG خالص: حلقات متحدة المركز تدور بسرعات متعاكسة (CSS animation 60–90s)، عقد متوهجة ذهبية/زمردية، ختم أم سارة في المركز داخل دائرة ذهبية رفيعة
- جوال: المدار يتحول لطبقة خلفية خافتة خلف النص المكدّس
- الأركان الأحادية (mono corners) والشريط المتدفق يبقيان

### ب. نظام الحركة الموحد
- كل الكشف: `var(--ease-expo)` + مدة 800ms + مسافة 28px + خيار blur(8px)
- العنوان: كشف كلمة-بكلمة (translateY 110% داخل قناع overflow-hidden + stagger 70ms)
- CTA: مغناطيسية نابضة (intensity 0.35، نطاق 90px) — مؤشر دقيق فقط
- تحت الشريط العلوي: خط تقدم قراءة ذهبي (scaleX، origin-right للـ RTL)
- reduced-motion: كل ما سبق يتعطل ويعرض الحالة النهائية

### ج. لحظة الإحصائيات
- أرقام `text-5xl→7xl` بتدرج ذهبي + فواصل شعرية عمودية + تسمية mono صغيرة
- الشريط يصبح نطاقاً كاملاً بخلفية `bg-card/40` وحدّين شعريين

### د. بطاقات تحريرية
- رقم فهرس شبحي عملاق (text-7xl، شفاف 6%) في زاوية كل بطاقة قسم
- سطر معاينة خدمات فرعية (أول 3 + «+N») تحت الوصف — قيمة محتوى حقيقية
- التحويم: خط شعري ذهبي + سهم منزلق + أيقونة تدور 3 درجات (موجود جزئياً)

### هـ. التيبوغرافيا والأداء
- خفض الخطوط: Cairo {400,700,800,900}→{700,800,900} · Amiri بدون مائل · Plex Arabic {400,500,700}
- توحيد سلم العناوين بعنصر clamp واحد للهيرو
- focus-visible: حلقة ذهبية موحدة عبر النظام
