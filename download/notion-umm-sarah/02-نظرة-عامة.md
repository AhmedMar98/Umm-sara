# منصة أم سارة — نظرة عامة على المشروع

## ما هي المنصة؟

منصة سعودية متخصصة في الخدمات الأكاديمية والبحثية، باللغة العربية (RTL) بالكامل. تخدم الطلاب والباحثين من أول بحث جامعي إلى رسالة الدكتوراه: الأبحاث والتقارير، الرسائل العلمية، التحليل الإحصائي، مشاريع التخرج، بناء السيرة الذاتية، وفحص الأصالة الأكاديمية.

## البنية التقنية

| الطبقة | التقنية | ملاحظات |
|---|---|---|
| الإطار | Next.js 16.1.3 (App Router + Turbopack) | 13 صفحة + مسارا API |
| اللغة | TypeScript (فحص صارم مفعّل في البناء منذ V10) | tsc = صفر أخطاء |
| الواجهة | React 19 + Tailwind 4 + shadcn/radix | نظام مكونات كامل |
| المشهد ثلاثي الأبعاد | three 0.186 + @react-three/fiber 9.7 | مشهد اللؤلؤة — lazy + SceneBoundary |
| الحركة | framer-motion 12.23 + lenis 1.3.26 | لغة حركة موحدة |
| التحقق | zod 4 | مسارات orders/consultations |
| قاعدة البيانات | Supabase (PostgreSQL + RLS) | schema.sql جاهز (6 جداول) |
| النشر | Render (خدمتان: Node + Docker/FastAPI) | render.yaml جاهز ومحاكى |

## الخريطة الوظيفية

- **الرئيسية:** هيرو سينمائي (مدار المعرفة SVG → مشهد اللؤلؤة 3D تدريجياً) + إحصائيات + 6 أقسام + عرض منتجين + آراء + CTA
- **الخدمات:** 6 أقسام × 31 خدمة فرعية مع بحث حي وفلترة
- **بنّاء السيرة الذاتية:** 3 قوالب (حديث/كلاسيكي/ATS) + معاينة حية + تصدير طباعة A4
- **فحص الأصالة:** وصف الخدمة + مسار الطلب
- **نموذج الطلب:** نموذج → API (zod) → Supabase → فتح واتساب برسالة معبأة
- **حجز الاستشارة:** مسار مستقل بتقويم مبسط

## أرقام رئيسية (مقيسة 2026-09-20)

- زمن البناء: 24.3 ثانية (18 صفحة، فحص TS مفعّل)
- زمن الاستجابة: 6–112ms لكل المسارات
- حجم الرئيسية: 25.6KB مضغوط (HTML) + 269KB JS أول تحميل + 26KB CSS
- الخطوط: 4 عائلات (Cairo · IBM Plex Arabic · Plex Mono · Amiri) مدمجة ذاتياً عبر next/font
- المستودع: 12+ كوميت موثق على فرعين (main + v10) مع tag خط الصفر
