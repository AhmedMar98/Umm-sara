## خطوات النشر الخمس

1. **GitHub:** إنشاء مستودع → `git remote add origin <url>` → `git push -u origin v10 && git push -u origin main`
2. **Render:** New → Blueprint → ربط المستودع (render.yaml يُقرأ تلقائياً: خدمتان)
3. **Supabase:** مشروع جديد → SQL Editor → تشغيل `supabase/schema.sql` → نسخ المفاتيح
4. **المتغيرات في لوحة Render:** `NEXT_PUBLIC_SUPABASE_URL` · `NEXT_PUBLIC_WHATSAPP_NUMBER` · `SUPABASE_URL` · `SUPABASE_SERVICE_ROLE_KEY`
5. **قبل أول نشر:** حذف `public/v5-screenshots.zip` (الأصل مبصم في download/baseline-v5/)

## تفاصيل تقنية مهمة

- `npm ci --legacy-peer-deps` ضروري وموثق السبب (سلسلة peerOptionl لـ @react-three/fiber تسحب react-dom فوق سقفها)
- `npm run start` = `node .next/standalone/server.js` (محايد للبيئة)
- النطاق: starter plan يكفي للانطلاق
- `turbopack.root` مثبت في next.config.ts (توصية رسمية عند تعدد ملفات القفل)
