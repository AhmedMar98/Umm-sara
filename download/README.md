## تحسينات v3 الجوهرية (v2 → v3)

1. **هيرو غير متماثل تحريري**: عمود نصي (يمين RTL) + مرساة بصرية «مدار المعرفة»
   (SVG خالص: حلقات متعاكسة الدوران + عقد متوهجة + ختم المنصة + هالة ضوئية) —
   درس الفيديوهات الثلاثة والمراجع
2. **كشف العنوان كلمة-بكلمة** بقناع overflow-safe يحمي التشكيل العربي (WordReveal)
3. **أزرار مغناطيسية نابضة** (Magnetic بنوابض framer-motion، مؤشر دقيق فقط)
4. **خط تقدم القراءة الذهبي** أسفل الشريط العلوي (ScrollProgress، origin-right للـ RTL)
5. **إحصائيات عملاقة** (text-5xl→7xl بتدرج ذهبي) + نطاق كامل + تسميات mono
6. **بطاقات أقسام تحريرية**: فهرس شبحي عملاق 01–06 + معاينة حقيقية لأول 3 خدمات فرعية
7. **منحنى حركة موحد**: كل الكشف عبر `--ease-expo` بثلاث تنويعات (انزلاق/ضباب/تكبير)
8. **حلقة تركيز ذهبية موحدة** عبر النظام (إمكانية وصول)
9. **أداء**: خفض ملفات الخطوط 16→11، ومدار بلا JavaScript، واستثناء مجلدات البحث عن ESLint/tsc
