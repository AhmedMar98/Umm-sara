## 3) أهم تغييرات الهوية (v1 → v2)

| العنصر | v1 | v2 |
|---|---|---|
| الخلفية الداكنة | #050807 محايد بارد | #080E0B فراغ غابي دافئ |
| النص | أبيض بارد | عاجي دافئ #F4F1E8 |
| الذهبي | #d6b25E مسطح | تدرج عتيق→شمبانيا #C5A059→#E8D48B يتحرك ببطء |
| الخطوط | Cairo + Plex | + **Amiri serif** لكلمات الفخامة |
| العمق | جزيئات مسطحة | 3 طبقات (غبار/متوسط/بوكيه) + أورورا + **حبيبات فيلم** |
| المؤشر | افتراضي | نقطة ذهبية + حلقة زمردية مغناطيسية |
| التمرير | CSS smooth | **Lenis** (القاسم الأعلى بين المواقع الستة الفائزة) |
| البطاقات | حد بسيط | خط شعري ذهبي + لمعان سفحي + ميلان 3D + فهرس رقمي |
| CTA الرئيسي | زمردي | **ذهبي متدرج** (قلب الأدوار — الذهب يتقدم) |
