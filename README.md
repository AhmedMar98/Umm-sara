# أم سارة | Umm Sara

منصة رقمية عربية بالكامل (RTL) للخدمات الأكاديمية والمهنية — من خدمات الجامعيين والدراسات العليا إلى تحليل البيانات والبرمجة والتصميم، مع منشئ سيرة ذاتية تفاعلي وفحص اقتباسات، تُقدَّم عبر واجهة ثلاثية الأبعاد هويتها البصرية المحورية: **اللؤلؤة والقوس**.

> **هوية محمية**: اللؤلؤة (Pearl) والقوس (Arch) مكوّنان مركزيان في الواجهة — قاعدة الحوكمة تمنع حذفهما أو استبدالهما، وكل تطوير يجري تحت مبدأ: احفظ → حسّن → سمُ بالهوية → تحقق.

## المسارات

| المسار | الوصف |
|---|---|
| `/` | الرئيسية — مشهد اللؤلؤة داخل القوس (three.js / R3F) |
| `/about` | عن المنصة |
| `/services` | فهرس الخدمات |
| `/services/[category]` | صفحات الفئات الست الديناميكية |
| `/cv-builder` | منشئ السيرة الذاتية التفاعلي |
| `/plagiarism-check` | فحص الاقتباسات |
| `/consultation` | طلب استشارة |
| `/contact` | التواصل |
| `/api/orders` · `/api/consultations` | واجهات الطلبات والاستشارات |

**الفئات الست**: خدمات الجامعيين · خدمات الخريجين · خدمات المدرسين · الإحصاء وتحليل البيانات · التصميم والدعم · البرمجة والتقنية.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الإطار | Next.js 16.1 (App Router، Turbopack) + TypeScript 5 |
| التصميم | Tailwind CSS 4 + shadcn/ui |
| المشهد ثلاثي الأبعاد | three.js 0.186 + @react-three/fiber 9.7 |
| الحركة | framer-motion 12.23 + Lenis 1.3 |
| التحقق والبيانات | zod 4 + Prisma (Supabase PostgreSQL) |
| الخدمة البرمجية | FastAPI (Python) — `api-service/` |

## التشغيل السريع

```bash
npm ci --legacy-peer-deps
npm run dev        # http://localhost:3000
```

البناء للإنتاج (standalone):

```bash
npm run build
npm start
```

> `--legacy-peer-deps` مطلوب: `@lexical/yjs` (تبعية @mdxeditor) يصرّح بـ peer على yjs لا يستخدمه التطبيق.

## البنية

```
src/app/            الصفحات والمسارات (App Router، RTL)
src/components/     المكونات — brand/ (اللؤلؤة والقوس) + أقسام الصفحات والحركات
src/hooks/ · src/lib/   المنطق المشترك والأدوات
api-service/        خدمة FastAPI (PDF والذكاء الاصطناعي لاحقاً)
supabase/           مخطط قاعدة البيانات المرجعي (PostgreSQL)
scripts/            سكربتات القياس والتحقق (بكسل / تباين WCAG / أداء)
download/           أدلة التحقق البصري (خط الصفر V5 → إصدار V10)
docs/               بوابة الإطلاق الرسمية
tests/              اختبارات التشغيل البنيوية
```

## منهجية الهندسة والحوكمة

يحكم هذا المشروع قاعدة صارمة: **لا دليل = لا نجاح** (No Evidence = No Pass)، وكل حالة إما `PASS` أو `FAIL` أو `UNVERIFIED`. سلسلة الأدلة كاملة في `worklog.md` و`BASELINE_V5.md`، وأبرز نتائج إصدار V10 المُقاسة:

- بناء الإنتاج **24.3s** بفحص TypeScript مُفعّل (صفر أخطاء)
- **13/13** مساراً يستجيب 200 — هرمية عناوين h1=1 في كل صفحة
- تباين ألوان **WCAG AA 14/14**
- JS أول تحميل **269KB gzip** — مشهد 3D بحجم 892KB مثبت lazy خارج التحميل الأولي
- هوية بصرية **4/4 متطابقة بالبكسل** مع خط الصفر المجمّد (V5)

البوابة الرسمية بالكامل: [`docs/V10_RELEASE_GATE.md`](docs/V10_RELEASE_GATE.md)
